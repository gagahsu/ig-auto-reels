# 主播造型庫：待機影片生成提示詞範本（Gemini Flow）

目標：做 7–14 支「同一個人、不同服裝／場景／姿勢」的待機影片，放進 Drive 的 `MyDrive/finreels/looks/`。
Colab 會依日期自動輪替（或用 `LOOK` 參數指定）。

**主要做法（單步驟）**：在 Flow 用 `avatar.jpg` 當參考圖（Ingredient），直接用文字指定新的服裝／場景／姿勢，一次生成待機影片。
**備用做法（兩步驟）**：單步驟臉漂移、位置不對時，改成先生成造型圖，再用 Frames to video 做影片（見第 4 節）。

---

## 0. 構圖規格（每支都要遵守）

小圓框（`Host.tsx` 的 `HostBubble`）是用固定位置裁切，所以每支影片的臉要在同一個位置，否則有的造型會切掉頭頂或只剩肩膀。
參考現有 `host_idle.mp4`（720×1280）量出來的位置：

| 項目 | 規格 |
|---|---|
| 比例 | 直式 9:16（720×1280 以上） |
| 臉部中心 | 水平約 **55%**、垂直約 **33–36%** |
| 頭頂（含頭髮） | 約 16% 高度 |
| 下巴 | 約 48% 高度 |
| 臉寬 | 約 30% 畫面寬 |
| 肩膀 | 左右延伸到畫面邊緣，半身到腰／手肘 |
| 臉部 | 正面或微側（15° 內），嘴巴自然閉合，手不擋臉 |
| 光線 | 臉部均勻柔和，不要強烈陰影、逆光、反光眼鏡 |
| 背景 | 淺景深；**背景不要有字或 logo**；避開大面積純白（會跟奶油底卡片混在一起） |

> 全螢幕的開場／結尾是整支影片滿版顯示，小圓框只截臉部那一塊，所以**臉位置一致**最重要。

## 1. 單步驟提示詞（主要做法）

在 Flow 上傳 `avatar.jpg` 當參考圖，貼上下面這段。要換造型，**只改【服裝／場景／姿勢】三行**。

```
直式 9:16 寫實影片，8 秒，鏡頭完全固定。

一位 30 歲左右的年輕女性，齊肩黑色長直髮、髮尾微內彎、側分，
鵝蛋臉，溫和自信的氣質，淡妝。

服裝：{服裝}
場景：{場景}，淺景深，背景虛化
姿勢：{姿勢}，手不要擋到臉

構圖：半身，臉部位於畫面水平 55%、垂直 35% 附近，頭頂留白約 15%，
肩膀延伸到畫面兩側，正面看鏡頭，柔和均勻光線。

動作：人物自然地看著鏡頭，只有輕微點頭、眨眼與呼吸。
嘴巴全程閉合，頭部與手部保持靜止，鏡頭不推拉不搖晃，背景靜止。
```

| 造型類型 | 加一句 |

## 2. 安全過濾：這些字眼不要放進提示詞

Flow 曾回覆「無法生成可能會損害名譽或扭曲時事的影片」。擬真人臉參考圖加上新聞／財經字眼，容易被擋，所以提示詞**刻意不要寫**：

- `財經主播`、`新聞主播`、`記者`、`播報` 等新聞角色字眼
- `台灣` 等地區加上財經／新聞的組合
- `與參考圖完全相同的人物`（可能被當成複製特定真人）
- 股票、指數、政治人物、公司名稱等時事內容

只描述外觀、服裝、場景與動作。被擋時本次不收費，可以安全重試。

若仍被擋，依序排查：
1. 先不傳參考圖，只用文字生成，確認提示詞本身沒問題。
2. 文字能過，再加回參考圖。
3. 參考圖會被擋，就改用第 4 節的兩步驟做法。

## 3. 檢查清單（每支都要看）

- [ ] 臉和 `host_idle.mp4` 是同一個人（髮型、五官、膚色）
- [ ] 臉部位置符合規格（中心約 55% / 35%），頭頂沒有被切到
- [ ] 8 秒內**嘴巴是閉著的**，沒有偷偷說話（否則對嘴會抖）
- [ ] 頭沒有大幅轉動、沒有手或物品擋到臉
- [ ] 首尾畫面相近（循環時不會跳）
- [ ] 背景沒有文字、logo、大面積純白
- [ ] 檔名格式 `lookNN_英文描述.mp4`

## 4. 備用：兩步驟（單步驟臉漂移或位置不對時）

1. **先生成造型圖**：在 Flow 用 `avatar.jpg` 當參考圖，提示詞如下。

   ```
   直式 9:16 寫實照片，一位 30 歲左右的年輕女性，齊肩黑色長直髮、髮尾微內彎、側分，
   鵝蛋臉，溫和自信的氣質，淡妝。
   服裝：{服裝}
   場景：{場景}，淺景深，背景虛化
   姿勢：{姿勢}，手不要擋到臉
   構圖：半身，臉部位於畫面水平 55%、垂直 35% 附近，頭頂留白約 15%，
   肩膀延伸到畫面兩側，正面看鏡頭，嘴巴自然閉合，柔和均勻光線，背景沒有文字或 logo
   ```

2. **再做影片**：用該圖當起始畫面（Frames to video），提示詞只要動作：

   ```
   8 秒，鏡頭完全固定。人物自然地看著鏡頭，只有輕微點頭、眨眼與呼吸。
   嘴巴全程閉合，頭部與手部保持靜止，背景靜止。
   ```

好處是影片前先確認臉、構圖和服裝，不合格只要重生成圖片。

## 5. 上傳與測試

1. 影片放到 Drive：`MyDrive/finreels/looks/`。
2. 先拿同一支 `voice.wav`，在 Colab 用 `LOOK` 逐支跑一次，看對嘴品質與臉部位置。
3. 合格的留在 `looks/`；不合格的重生成，不要混進去。
4. 用 `--still` 檢查小圓框是否切到頭：
   `node render.mjs build/<date>/props.json out/x.png --still=300`

MuseTalk 是按檔名排序後，用「日期序號 % 支數」選造型，所以**新增造型只要丟進 `looks/`**，不用改程式。想固定某天用某造型，Colab 第 1 格填 `LOOK`。

## 6. 提醒

- IG 發文時開啟「AI 生成」標籤。
- 造型之間不要差太多（髮型、年齡感固定），觀眾才會當作同一個主持人。
